Quick Install

UP IN
60 SECONDS

Four commands. One tool. Everything you need to start pulling media from any platform on your Android device.

01
Setup Termux
$ pkg update && pkg upgrade -y
$ pkg install python git ffmpeg -y
02
Install Python Deps
$ pip install yt-dlp rich
03
Clone Repository
$ git clone https://github.com/rafiqdev1/vic.git
$ cd vic
$ pip install -r requirements.txt
04
Launch Vidly Pro
$ python vidly.py
# Enjoy downloading!
Core Features

BUILT FOR
POWER USERS

Every feature is optimized for the Termux environment — fast, lightweight, and designed to work flawlessly on Android.

Multi-Quality Video
Choose between Best, 1080p, 720p, 480p or audio-only. The format engine selects the optimal codec combination automatically.
MP3 Audio Export
Extract audio at 192kbps quality via FFmpeg post-processing. Perfect for offline listening.
Playlist Support
Download entire playlists in one command with sequential processing.
Fast Downloads
Powered by yt-dlp — the fastest, most reliable fork of youtube-dl.
Live Progress Bar
Real-time download progress with ETA, speed indicator, and spinner — powered by the Rich terminal library for a polished CLI experience. Custom output folder support included.
Metadata Embedding
Automatically embeds title, thumbnail, and metadata into every downloaded file via FFmpegMetadata post-processor.
